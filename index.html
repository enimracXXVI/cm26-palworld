First-time setup / using a different sheet
  1. Open the Palpedia Field Tracker Data sheet already created in your Drive (or any Google Sheet of your own).
  2. Open Extensions → Apps Script, delete the placeholder code, and paste in the script below.
  3. In the Apps Script editor: Project Settings (gear icon) → Script Properties → add a property named SECRET with any password you choose.
  4. Deploy → New deployment → type Web app → Execute as Me, Who has access Anyone → Deploy, then authorize it.
  5. Copy the Web app URL it gives you and paste it above, along with the same SECRET.
  6. Once connected, six tabs are used on the sheet: pals (id/palId/name/type/imageUrl/discovered — the app writes imageUrl and discovered as you use it), partnerSkills (id/palId/palName/name/description — its own tab), passiveSkills (id/name/rank/surgery/effects/unlocked — the app writes unlocked, adding that column itself if it's missing), activeSkills (id/name/element/power/ct/exclusive/description/notes — paste your own data, only name is required), elements (id/code/name/imageUrl — the 9 types), and breedingLog (fully owned by the app). Any tab that already exists keeps exactly the columns you've set up — nothing is renamed or reordered.

Already connected and pasting in an updated script? Editing the code alone doesn't update your live URL — go to Deploy → Manage deployments → pencil icon → Version: New version → Deploy.
