Google Sheet sync

Store your breeding log, Pal pictures, and an active-skills reference in a Google Sheet you own, so it survives across devices and browsers.

  1. Open the Palpedia Field Tracker Data sheet already created in your Drive (or any Google Sheet of your own).
  2. Open Extensions → Apps Script, delete the placeholder code, and paste in the script below.
  3. In the Apps Script editor: Project Settings (gear icon) → Script Properties → add a property named SECRET with any password you choose.
  4. Deploy → New deployment → type Web app → Execute as Me, Who has access Anyone → Deploy, then authorize it.
  5. Copy the Web app URL it gives you and paste it below, along with the same SECRET.
  6. Once connected, four more tabs appear on the sheet: PalsDB (every Pal, pre-filled with Partner Skills — paste a picture URL into ImageUrl; Discovered is written by the app as you tick Pals off), PassiveSkillsDB (pre-filled with the app's passive skill list — edit or add rows and the app uses your copy), ActiveSkillsDB (empty — paste your own active-skill data, at least a Name column), and ElementsDB (the 9 types — paste a picture per type to replace the colored pills).

Already connected and pasting in an updated script? Editing the code alone doesn't update your live URL — go to Deploy → Manage deployments → pencil icon → Version: New version → Deploy.
